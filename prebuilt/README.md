# Prebuilt systems

Ready-to-load files for every system measured in this repository: the XSA
(bitstream + PS initialisation) and the benchmark ELFs for ML-DSA-44, -65 and
-87 (`mode2`, `mode3`, `mode5`). Loading them needs only `xsdb` (part of
Vivado, Vitis or the free Vivado Lab Edition) and Python 3 with `pyserial`; no
HLS, Vivado or Vitis build is required.

| Folder | System (PL 50 MHz) | XSA | ELF backend | Logs in [`results/uart`](../results/uart) |
|---|---|---|---|---|
| `v1` | Keccak-f v1, AXI4-Lite | `keccak_f_system.xsa` | `v1` + `keccak_test_v1.elf` | `*_v1_*`, `keccak_test_v1_uart.txt` |
| `v2` | Keccak-f v2, AXI4 master on HP0 | `keccak_f_system_maxi.xsa` | `v2` + `keccak_test_v2.elf` | `*_v2_*`, `keccak_test_v2_uart.txt` |
| `v3` | Keccak-f v3 multiblock on HP0 | `keccak_multiblock.xsa` | `v3` | `*_v3_1000msg*` |
| `ntt` | v3 + forward NTT, 32-bit master, shared HP0 | `keccak_multiblock_ntt8.xsa` | `v3-ntt` | `*_v3_ntt8_*` |
| `ntt64` | v3 + forward NTT, 64-bit master, shared HP0 | `keccak_multiblock_ntt8w64.xsa` | `v3-ntt64` | `*_v3_ntt8w64_*` |
| `ntt64bi` | v3 + forward/inverse NTT, shared HP0 | `keccak_multiblock_ntt8w64bi.xsa` | `v3-ntt64bi` | `*_v3_ntt64bi_1000msg*` |
| `final` | v3 on HP0 + forward/inverse NTT on HP2 | `keccak_multiblock_ntt8w64bi_hp2.xsa` | `v3-ntt64bi` | `*_v3_ntt64bi_hp2_*` |

## Use

Boot jumpers JP7–JP11 on GND (JTAG), cable on PROG (J17):

```sh
export XILINX_ROOT=/path/to/Xilinx/2026.1 && source scripts/env.sh   # or any xsdb in PATH
make check-prebuilt                        # verify SHA256SUMS
make program-prebuilt VARIANT=v2 MODE=3    # load one system and one level
make uart MODE=3                           # cable on UART (J14); summary after about one minute
```

Every system and level in one go (23 runs, about 40 minutes); the logs go to
`build/campaign/` with the same names as in `results/uart`:

```sh
make measure-all          # = python3 scripts/measure_all.py [--systems v3 final] [--modes 2]
```

With two micro-USB cables (J17 and J14) the campaign runs unattended. With one
cable the script prints which port it needs and continues as soon as the cable
is moved.

## Provenance

All files were produced by the scripts of this repository with AMD Vivado and
Vitis **2026.1** (Vivado build 6511674) and the `arm-none-eabi-gcc` shipped
with Vitis, from the sources of commit `6456251`.

- **`final`**: the XSA and the three ELFs used for the measurements in
  [`results/`](../results). A clean rebuild (`make hls && make bitstream`)
  produced a bitstream with identical configuration data (4 045 520 bytes);
  only the build date in the `.bit` header differs.
- **`v1` … `ntt64bi`**: rebuilt from scratch with `make hls-*` and
  `make bitstream VARIANT=<folder>`. Timing and utilization are identical to
  the reports of the measured systems in
  [`results/implementation`](../results/implementation) (v1: to the figures in
  [docs/benchmark.md](../docs/benchmark.md), its report was not kept).
- **ELFs**: `python3 sw/mldsa/build.py board <backend> --mode N` (and
  `--keccak-test` for v1/v2) against the BSP of the final XSA, followed by
  `arm-none-eabi-strip --strip-debug`, which removes the debug information and
  with it the build paths. A rebuilt ELF loads exactly the same code and data
  as the measured one except for the 20-byte GNU build ID, which
  `sw/platform/lscript.ld` places at the end of `.text`.
- `ntt64bi` and `final` use the same three ELFs. The `v3-ntt` and `v3-ntt64`
  ELFs are identical: the 32- and 64-bit forward NTT IPs have the same
  register map, and only the bitstream differs.

Integrity: `SHA256SUMS` (`make check-prebuilt`).
